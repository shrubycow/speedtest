# Network Speed Tester (urllib)

Простой консольный скрипт на Python для измерения скорости скачивания данных с веб-серверов. Написан исключительно с использованием **стандартной библиотеки Python**, поэтому не требует установки сторонних пакетов (таких как `requests` или `httpx`).

## 🚀 Особенности

* **Отказоустойчивость:** Скрипт перехватывает сетевые сбои, HTTP-ошибки сервера (например, 404 или 500) и таймауты. При возникновении первой же проблемы он выводит понятное сообщение и корректно завершает работу с кодом `1`.
* **Обратная совместимость:** Использование `from __future__ import annotations` позволяет запускать скрипт на ранних версиях Python, сохраняя современные подсказки типов.
* **Точные замеры сети:** Чтение данных происходит небольшими порциями (чанками по 8 КБ). Это минимизирует нагрузку на оперативную память (RAM) и исключает влияние процессора на результаты замеров.
* **Кастомное количество проверок:** Позволяет проводить серию тестов для вычисления более точной средней скорости.

## 🛠️ Требования

* **Python 3.7** или выше (благодаря директиве совместимости аннотаций).

## 💻 Использование

Запустите скрипт из терминала или командной строки, передав обязательный аргумент — **URL файла или страницы**, скорость скачивания которых нужно проверить.

```bash
python main.py <URL> [опции]
```

### Примеры запуска

1. **Простой тест (10 повторений по умолчанию):**
   ```bash
   python main.py https://hetzner.de
   ```

2. **Тест с измененным количеством повторов (например, 3 раза):**
   ```bash
   python main.py https://hetzner.de -r 3
   ```
   или используя полную форму флага:
   ```bash
   python main.py https://hetzner.de --retries 3
   ```

### Справка по аргументам

Вы можете вызвать встроенную справку в любой момент:
```bash
python main.py --help
```

**Доступные параметры:**
* `url` — *(Обязательный)* URL-адрес для проверки速度.
* `-r`, `--retries` — *(Опциональный)* Количество повторов запроса для вычисления среднего значения. По умолчанию: `10`.

## 📊 Пример вывода в консоль

**При успешном тесте:**
```text
Скорость запроса #1: 45.1204 мб/с
Скорость запроса #2: 48.6510 мб/с
Скорость запроса #3: 43.1982 мб/с
Средняя скорость: 45.6565 мб/c
```

**При падении (например, неверный URL):**
```text
[Ошибка сети]: <urlopen error [Errno -2] Name or service not known>
```
*В этот момент выполнение прерывается, а операционная система получает код возврата `1`.*

## 🔍 Как это работает изнутри

1. Функция `measure_one_request` отправляет HTTP-запрос с помощью встроенного подмодуля `urllib.request.urlopen`.
2. Время замеряется высокоточным системным таймером `time.perf_counter()`.
3. Данные скачиваются из сетевого сокета порциями по 8 КБ (`CHUNK_SIZE`) и сразу же удаляются из памяти (не сохраняются в переменные), чтобы замерять исключительно **пропускную способность сети**.
4. Скрипт переводит байты в Мегабайты (используя коэффициент $1024 \times 1024$) и делит на затраченное время, выводя результат в **Мбайт/с**.
